Trade Zone Validator
====================

Trade Zone Validator is a lightweight, containerized PHP application for managing and monitoring custom price zones for XAU/USD, XAG/USD, and BTC/USD. It supports real-time price checks and sends alerts via Telegram when zones are entered, retested, or invalidated. Built with simplicity in mind, it uses an SQLite database and runs entirely in Docker.

-----------------------------------------------------
Features
-----------------------------------------------------

- Admin Authentication – Single-user system with login-protected dashboard.
- Zone Management – Create, edit, or delete price zones with direction and notes.
- Live Monitoring – Continuously fetches live XAU, XAG, BTC prices via Gold API.
- Telegram Alerts – Get notified for zone entry, retest, or invalidation events.
- Containerized – Easily deploy using Docker and Docker Compose.

-----------------------------------------------------
Project Structure
-----------------------------------------------------

app/
├── config/        # Configs (API key, Telegram bot, DB path)
├── db/            # SQLite database file (autogenerated)
├── public/        # Web UI (login, dashboard, zone editor)
├── scripts/       # DB initialization script
└── worker/        # Background price monitor

Dockerfile          # Builds Apache + PHP app
docker-compose.yml  # Launches the container
runner.sh           # Entrypoint: sets up DB + starts worker

-----------------------------------------------------
Setup Instructions
-----------------------------------------------------

Prerequisites:
- Docker
- Docker Compose

Getting Started:
1. Run the app:

   docker-compose up --build

2. Visit the app at: http://localhost:8000

3. Register the first admin user.
4. Go to Settings and add your Telegram bot token and chat ID.
5. Start adding zones and receive live alerts.

-----------------------------------------------------
Application Flow
-----------------------------------------------------

On container startup:
- runner.sh executes:
  - init_db.php to create users and zones tables (if missing)
  - Starts Apache
  - Loops monitor.php every 10 seconds

Web UI:
- register.php → Create initial admin (only if no users exist)
- login.php → User login with session auth
- index.php → Dashboard for zone list and price display
- add_zone.php / edit_zone.php → Zone creation/editing

Each zone includes:
- Lower bound
- Upper bound
- Direction (Uptrend / Downtrend)
- Optional remark

-----------------------------------------------------
Telegram Alerts
-----------------------------------------------------

Telegram credentials are stored securely in the users table via settings.php.

Alert types:
- Zone Entered → Price enters defined range
- Retest → Price temporarily breaks zone boundary (based on direction)
- Invalidation → Price completely invalidates the zone

Invalidated zones are automatically deleted.

-----------------------------------------------------
Monitoring Logic
-----------------------------------------------------

File: worker/monitor.php

- Fetches live prices from:
  https://api.gold-api.com/price/XAU
  https://api.gold-api.com/price/XAG
  https://api.gold-api.com/price/BTC

Example JSON response:
{
  "name": "Gold",
  "price": 3326.840088,
  "symbol": "XAU",
  "updatedAt": "2025-07-08T09:46:25Z"
}

Logic per zone:
- Enters zone → send alert + store entered_at
- 10 minutes after entry:
  - Uptrend:
    - Price < lower bound → Retest alert
    - Price > upper bound → Invalidate
  - Downtrend:
    - Price > upper bound → Retest alert
    - Price < lower bound → Invalidate
- Retested zones may re-enter and repeat the cycle

Log file location: /var/www/worker/monitor.log

-----------------------------------------------------
Tips & Notes
-----------------------------------------------------

- Persist database by mounting app/db/ as Docker volume
- Change polling interval in runner.sh (default: 10 seconds)
- View logs:
  docker-compose logs -f
  OR
  docker exec -it <container_id> tail -f /var/www/worker/monitor.log
